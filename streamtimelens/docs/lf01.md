# LF-01 development contract

LF-01 was the research cycle after JQ-01 closed and is now closed after r2. It
keeps ingestion and the query-independent Frozen Visual V2 snapshot unchanged. At query time only,
the reader projects the query and every visible persisted temporal embedding,
runs bounded cross-attention, emits per-token saliency, and scores the unchanged
Frozen V2 final plus frozen X1 Top-8 candidate pool.

## T0/J1 scope

The first milestone is effect-free. It does not open the 552 development
annotations and does not prepare or consume D-lock. Its frozen contract is:

- only a verified `SnapshotReader`, query embedding, Frozen V2 row, frozen X1
  candidate geometry, and an LF checkpoint may enter inference;
- all query-visible temporal tokens are consumed in timestamp/frame-ref order;
  a snapshot with more than 256 tokens fails closed instead of being silently
  sampled or truncated;
- a 64-dimensional, four-head query-to-token attention block produces global
  query context, per-token saliency, and candidate quality logits;
- the candidate pool remains Frozen V2 final plus at most eight frozen X1
  extents; no threshold, margin, Top-K, cell, ridge, or ingestion tuning is
  introduced;
- score ties use candidate ID ordering, and any invalid token, future token,
  schema/checkpoint mismatch, missing checkpoint, non-finite output, unverified
  reader, or inference exception returns the Frozen V2 row bit-exact;
- inference hashes every allow-listed snapshot file before and after execution;
  query-time output and debug data are written outside the snapshot.

The implementation lives in `retrieval/late_fusion.py` and is deliberately
independent from `retrieval/joint_quality.py`, whose JQ-01 model contracts remain
closed and unchanged.

Run the effect-free gate from a clean commit:

```bash
python3 scripts/run_lf01_mechanism_gate.py
```

It writes the resolved config, Git revision, provenance, schema, a complete
synthetic nine-candidate/token trace, test output, and artifact checksums below
`work/results/<full-git-sha>/lf01/T0_J1/`.

## V2-original r1 effect contract

After T0/J1 passes, r1 reuses exactly the consumed 552 observations and four
whole-video folds used by JQ-01. X1 candidate generation is cross-fitted inside
every outer and inner boundary. The held-out video's GT reaches neither X1 nor
the LF reader, optimizer, negative pairing, nor epoch selection.

The single frozen r1 objective is a weighted sum of balanced in-GT token
saliency BCE (`0.5`), deterministic true cross-video negative-pair all-zero
saliency BCE (`0.5`), candidate IoU SmoothL1 (`1.0`), observation-local ListNet
quality ranking (`1.0`), and relative baseline-regret (`1.0`). Training is
video-equal AdamW at `1e-3`, weight decay `1e-4`, at most 100 epochs and patience
10. CUDA runs set `CUBLAS_WORKSPACE_CONFIG=:4096:8` before CUDA initialization;
this runtime setting is part of the resolved contract. The inner validation fold selects only the epoch by video-equal candidate
mIoU. No threshold, model-size, loss-weight, candidate, or geometry search is
allowed within r1.

The first launch at commit `610d5df44b41690917b7eb1fe473447cee7ac1e6`
was stopped before any OOF prediction because this cuBLAS setting was missing.
That launch has no effect conclusion; its failure artifact is retained under
that commit's result directory. The only correction is the deterministic
runtime declaration above—model, data, losses, folds and gates are unchanged.

All of the following are required to freeze r1:

- standard mIoU exceeds both Frozen V2 and JQ r2 (`0.400079`), video-equal
  mIoU delta and its 95% bootstrap lower bound are positive, and standard
  R@0.7 does not regress;
- every rho slice is at least `-0.02`, good-baseline video-equal delta is at
  least `-0.01`, and at least 20% of union-oracle recoverable delta transfers;
- preloaded-model query readout p95 is at most 250 ms on the configured device;
- snapshot, byte, fold, baseline bit-exact, provenance and coverage gates pass.

Failure means r1 is not frozen and cannot enter D-lock. It does not authorize a
post-hoc threshold or hyperparameter sweep; any later structural revision needs
a new explicit contract and clean commit. D-lock remains deferred.

## V2-original r1 result and r2 structural contract

r1 completed all 552 OOF observations at commit
`ad2381daf9954ed79211afaabe4381cf5f5e932e`. Standard mIoU changed from
`0.392039` to `0.385787` (`-0.006252`), video-equal delta was `-0.016481`
with 95% CI `[-0.036396,+0.003197]`, while standard R@0.7 improved by
`+0.036232`. Readout p95 was `3.408 ms`; snapshot, byte, fold, baseline and
provenance gates passed. The result is not frozen and does not enter D-lock.

The fixed-result diagnosis showed fold-level replacements of `7/0/141/1`.
Absolute candidate-quality logits were therefore not calibrated consistently
across outer folds: among 149 replacements, 67 helped and 74 harmed, with the
largest regression concentrated on stronger baselines.

r2 is one structural correction, not a threshold revision. It retains the
same global token reader, candidate pool, data, folds, optimizer, model width,
attention, epoch selection and latency/effect gates. The final head now compares
each candidate state directly with the Frozen V2 candidate state and predicts
candidate-minus-baseline gain. Frozen V2 receives selection logit exactly zero;
successors use their learned gain logits, followed by threshold-free stable
argmax. Absolute IoU quality remains auxiliary, gain SmoothL1 has weight `1.0`,
and relative regret has weight `2.0`. No r2 setting is selected from a grid.

## Final decision

LF-01 is closed after r2. Commit
`816676de4c6c87ac4d5ab134e204fae4426da864` passed the revised T0/J1 and
completed all 552 OOF observations. Standard mIoU changed from `0.392039` to
`0.383233` (`-0.008806`), video-equal delta was `-0.020745` with 95% CI
`[-0.046067,+0.002217]`, standard R@0.7 changed by `+0.009058`, and
good-baseline delta was `-0.059123`. Readout p95 was `3.576 ms`; snapshot,
byte, fold, baseline and provenance gates passed.

r2 selected an extent only in outer fold 1 (`99` observations); folds 0, 2 and
3 selected Frozen V2 for every observation. Of those 99 replacements, 43
helped and 54 harmed. Thus direct relative gain did not resolve the cross-fold
generalization failure. No further LF feature, loss, head, threshold, model-size
or candidate adjustment is authorized, and D-lock remains unprepared and
unconsumed.

The immutable r2 `summary.json` and appended registry use the legacy decision
string `lf01_r1_not_frozen`; the artifact's `revision=v2-original-r2`, code SHA
and all metrics are correct. Later code changes the generic label to
`lf01_revision_not_frozen` without rewriting that result.
